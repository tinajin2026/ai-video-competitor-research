行业总览竞品研究X 动态数据与方法

数据、证据与更新方式

本研究站覆盖 37 个产品对象、41 个根域。网站访问来自 TabAPI 的第三方估算；官网动作与价格来自官方页面。流量月份为 2026-08，官网采集日期为 2026-10-02。两个时间窗口分别呈现。

如何使用

行业总览看固定样本和赛道分化；竞品研究进入每家公司独立 HTML；公司页依次拆解增长、渠道、关键词、地区、产品动作和可验证实验。对比页可自由选 2—6 家，导出当前筛选。证据链接可返回官网或下载公开研究数据。

为什么最新仍是 8 月

10 月 2 日重新请求了全部 41 个根域，41 个 HTTP 200，overview.month 全部为 2026-08；最近三个月返回 6、7、8 月。尚未取得 9 月和 10 月，不能把重新请求日期当作统计月份。TabAPI 官方接口只暴露 trailing months（3—12），没有指定月份或实时查询参数。逐域重新请求记录 · 官方文档

我们实际测量什么

访问次数是会话级域名估算，不是用户、付费人数或收入。跳出率、时长、访问页数不等于留存。Direct 可能包含品牌访问、书签、未归因分享等，不能据此断言品牌忠诚。渠道折算访问 = 全站访问估算 × 同月份额，不是投放花费。

关键词字段 volume 是词的月搜索量，不是给本站带来的访问。品牌、第三方品牌与通用任务按词面标注，样本词数不是流量份额。地区只返回前列样本，不代表完整市场分布。单个地区份额不推算 ARPU。

固定样本与计算

宏观使用 3—8 月持续有数据的 27 个主域，按域名去重。排除共享母域、迁移域和停服对象；这些公司仍有独立研究页。样本含综合创作与开发者业务，因此不是整个 AI 视频市场规模。

  • 月环比 = 8 月访问 / 7 月访问 − 1。
  • 近三月均值变化 = 6—8 月平均访问 / 3—5 月平均访问 − 1。
  • 指数首月 = 100；缺月不插值。Runway、Kling 新旧域分别展示。
  • 同行基准使用同赛道合格主域，且移除当前公司；不跨赛道生成健康分。

已知缺口

Happy Horse 官网正文不足；Haiper 主页抓取失败。均保留流量和身份信息，但不补造增长动作。没有完整广告素材库、广告花费、竞品转化、留存或付费数据。Higgsfield 与 Topview 重点投放研究仍需广告主体与素材原帖证据，不能将同名 TikTok TopView 广告位算入 Topview。

60 条官网动作覆盖 35 家；没有日期的记录只标为“10 月 2 日观察”。官网自报营收与客户效果不属于独立验证。9—10 月动作不能归因为 8 月增长。具体分析将观察事实与我们建议的实验分开。

接入 Grok BOT 与 GitHub

站点已拆为数据、分析规则和页面三个层次。每家公司有稳定 product_id、独立 URL 与 JSON。Grok BOT 将 X 原帖写为 JSONL，经校验脚本处理后，重新构建即可更新页面；无需改 HTML。当前尚未连接 Grok、X API 或定时任务。

公开站点没有上传写入接口。机器人在受控 GitHub 仓库内提交 data/inbox/*.jsonl，由工作流校验、构建并发布 GitHub Pages。当前 Sites 链接是本次发布快照，与 GitHub Pages 是两个独立部署目标；建库后若采用 Pages，以 Pages 链接作为持续更新地址。

数据格式、幂等规则、运行命令和最小权限建议随源码包提供。X 账号初始映射来自用户清单；接入前应核对官方身份，复用 OpenAI 等公司账号时必须提供产品相关性依据。
